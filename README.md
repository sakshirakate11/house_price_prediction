🏠 House Price Prediction System

AI-powered web application that predicts house prices using Machine Learning and Flask. Built with Python, Scikit-learn, and Tailwind CSS, it provides real-time predictions based on user inputs like area, bedrooms, and bathrooms.

🚀 Features:
✔️ ML model (Linear Regression)
✔️ Real-time prediction
✔️ Clean responsive UI
✔️ Flask backend integration

🧠 Tech Stack: Python | Flask | Scikit-learn | Tailwind CSS

👉 Run the app: "python app.py"
👉 Open: http://127.0.0.1:5000/
